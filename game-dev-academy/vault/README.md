# Your Vault (DoSa Vault)

Sam's ideas, research and Insight Log live in an Obsidian vault called **DoSa Vault**, on Sam's PC at `C:\Users\Samca\Documents\DoSa Vault\`. That vault **wasn't available** when this academy was written, so nothing from it is in this repo yet. The academy uses the core facts from Sam's **roblox-player-mind** skill instead.

## Bringing your vault in

Pick what you're comfortable sharing (this repo is public on GitHub):

- **Keep it private (recommended):** leave the vault where it is. The `game-dev-mentor` and `roblox-player-mind` skills read it from your machine.
- **Share selected notes:** copy idea briefs or design notes you don't mind being public into this folder, e.g. `vault/Ideas/<idea>.md`. Never copy analytics exports with player data, private notes, or anything with personal info.

Suggested vault layout (matches the skills):

```
DoSa Vault/
├── Ideas/                       ← one note per idea (templates/idea-brief.md)
├── Research/                    ← market notes, teardowns, trend log
├── Design/
│   └── Roblox Player Mind.md    ← research + Insight Log (used by the roblox-player-mind skill)
└── Games/<Game>/
    ├── <Game>.md                ← funnels, events, past changes
    └── Playtests/<date>.md      ← templates/playtest-notes.md
```
